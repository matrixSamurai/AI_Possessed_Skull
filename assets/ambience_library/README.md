# MALACHI selected sound effects

These 12 ElevenLabs effects were supplied by the project owner for inclusion in
this repository. `originals/` preserves the uploaded MP3s without alteration.
The WAVs are playback copies: 16 kHz mono PCM16, capped at 30 seconds for the
existing player. `manifest.json` records source filenames, durations and SHA-256
checksums. All effects retain their original names, including the two distinct
Dark_horror_backgrou recordings.

Use `AMBIENCE_DIRECTORY=assets/ambience_library` and
`AMBIENCE_FRESH_EFFECTS_ENABLED=false`. The existing shuffle bag uses all effects
before repeating and avoids immediate repeats. No ElevenLabs API call is required
for playback.
